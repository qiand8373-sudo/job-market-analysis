# 数据岗求职市场分析（Job Market Analyzer）

> 数据分析学习项目：分析数据类岗位的招聘市场，为求职决策提供数据支撑。

## 项目目的

大三寒假实习备战项目，解决两个问题：

1. **数据岗到底需要什么**：技能要求、学历门槛、薪资水平、城市分布
2. **怎么找到个人直招的兼职/实习**：过滤中介信息，识别可信岗位

## 数据源

| 数据源 | 用途 | 状态 |
|--------|------|------|
| 招聘网站公开信息 | 数据岗 JD 采集 | 待开发 |
| 国家统计局等公开数据 | 薪资/就业宏观数据 | 待接入 |
| 小红书公开笔记 | 兼职/实习信息挖掘（子模块） | 待开发 |

## 项目结构

```
├── data/                  # 数据（不入库）
│   ├── raw/               # 原始采集数据
│   └── processed/         # 清洗后数据
├── src/
│   ├── crawler/           # 数据采集（BOSS / 小红书）
│   ├── cleaning/          # 数据清洗
│   ├── extraction/        # LLM 结构化抽取（技能标签/岗位信息）
│   ├── analysis/          # 数据分析与建模
│   └── dashboard/         # Streamlit 可视化看板
└── learning/              # Python 学习练习记录
```

## 亮点模块

- **JD 技能标签抽取**：大模型从职位描述中结构化抽取技能要求 → 技能-薪资关联分析
- **中介识别**：规则 + 大模型识别小红书兼职信息中的中介发布，产出可信度标签
- **数据安全规范**：联系方式展示脱敏，原始数据不入库

## 声明

本项目仅用于个人学习与求职分析，不商用。原始数据不对外公开。
