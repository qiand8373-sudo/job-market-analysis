分析数据类岗位的招聘市场（技能要求 / 学历门槛 / 薪资水平 / 城市分布），并利用大模型从 JD 文本中结构化抽取技能标签，做技能-薪资关联分析，为大三寒假数据分析实习求职提供数据支撑，同时作为简历项目。

**做**：
- 招聘数据清洗流水线（去重 / 缺失值 / 薪资字段解析）

## 6. 项目结构

```
├── data/
│   ├── raw/          ← 现成数据集 CSV（不入库）
│   └── processed/    ← 清洗后 CSV + SQLite 库 + 抽取结果 jsonl
├── notebooks/        ← Jupyter 主战场，每阶段一个 01_xxx.ipynb
├── src/
│   ├── cleaning.py   ← 从 notebook 提炼的可复用清洗函数
│   ├── extraction/   ← LLM 技能抽取（阶段 5）
│   ├── analysis/     ← 深度分析函数（阶段 4）
│   └── dashboard/    ← Streamlit 看板（阶段 6）
├── learning/         ← 学习笔记与练习
└── docs/             ← 设计文档
```

**关键理念**：先在 notebook 里把分析写通 → 把可复用部分提炼成 src/ 里的函数。既学"怎么做分析"，又学"怎么组织代码"。

## 7. 数据流

```
data/raw/（原始 CSV，永不动）
   ↓ 阶段2：cleaning.py（去重/缺失值/薪资解析）
data/processed/（清洗后 CSV）
   ↓ 阶段3：导入 SQLite
   ↓ 阶段4-5：pandas 分析 + LLM 抽取（结果存 processed/*.jsonl）
   ↓ 阶段6：Streamlit 看板读取 processed 展示
```

## 8. 组件职责

| 组件 | 职责 | 依赖 |
|------|------|------|
| notebooks/ | 分析主战场，每步结果可见（零基础友好） | data/processed |
| src/cleaning.py | 可复用清洗函数，输入 raw CSV 输出 processed CSV | pandas |
| src/extraction/ | 调用千问 API 抽取 JD 技能标签，限速+断点续跑 | openai SDK、.env |
| src/analysis/ | 深度分析函数（关联分析、矩阵） | pandas |
| src/dashboard/ | Streamlit 看板，读 processed 数据展示核心图表 | streamlit |

## 9. 错误处理与风险预案

| 风险 | 预案 |
|------|------|
| 数据集字段混乱/缺关键字段 | 阶段 0 第一件事探查数据质量，不行立刻换数据集（备选 ≥ 2 个） |
| 千问 API 调用失败/超限 | 限速 sleep + 失败重试 + 结果缓存 jsonl 断点续跑；兜底：关键词规则匹配替代 LLM |
| API key 泄露 | key 放 .env（已在 .gitignore） |
| 进度落后 | 第 13 周缓冲；砍深度分析的可选小节，不砍主线 |
