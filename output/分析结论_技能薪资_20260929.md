# 数据岗技能-薪资关联分析结论（2026-09-29）

> 样本：BOSS 直聘公开岗位 2,982 条（清洗去重后），月薪口径正式岗 1,934 个
> 城市：深圳 433 / 西安 452 / 北京 279 / 广州 395 / 上海 375

## 结论 1：技能需求地图——Python + SQL 是数据岗入场券

| 排名 | 技能 | 出现次数 |
|------|------|---------|
| 1 | Python | 277 |
| 2 | SQL | 156 |
| 3 | 数学/统计相关专业 | 148 |
| 4 | 计算机相关专业 | 124 |
| 5 | 数据分析/挖掘经验 | 120 |

**含义**：Python 和 SQL 合计占技能出现总次数的 6.9%，是数据岗最硬的通货。简历中这两个技能必须放在最显眼位置，且要有项目证据支撑。

## 结论 2：技能溢价——经验与算法类技能溢价最高

| 技能 | 含技能平均月薪 | 溢价（vs 全体均值 22.4K） |
|------|--------------|------------------------|
| 机器学习经验 | 36.6K | +63.7% |
| 数据挖掘 | 35.7K | +59.6% |
| 大数据处理经验 | 35.3K | +57.5% |
| C/C++ | 30.9K | +38.2% |
| 机器学习 | 30.3K | +35.5% |
| 大模型算法 | 27.1K | +20.9% |

**含义**：同样的岗位名，带"机器学习/数据挖掘"标签的薪资高 60%——技能深度直接体现在薪资上。实习阶段无法凭空获得"经验"，但可以通过项目体现方法论（建模、挖掘）而非工具操作。

## 结论 3：城市薪资梯度——上海最高，西安是洼地但机会最多

上海 29.6K > 深圳 26.3K > 北京 25.5K > 广州 18.6K > 西安 14.0K
西安岗位数最多（452 个）但薪资最低——适合实习起步，不适合攒钱。

## 结论 4：学历门槛——本科够用

本科 74%（1,429 个），硕士仅 3.8%。数据岗实习/初级岗本科是主流口径。

## 个人策略含义（结合自身情况）

1. **简历优先级**：Python、SQL、数据挖掘、机器学习方法论——按溢价排序组织技能栏
2. **项目选择**：已有 3 个项目分别覆盖 SQL 分析（Olist）、归因建模（营销）、统计建模（足球预测）——正好对上"数据分析/挖掘经验"的技能标签
3. **城市选择**：实习阶段优先深圳（薪资第 2 + 岗位多），寒假实习无需纠结长期收入
